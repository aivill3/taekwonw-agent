# collecting — 수집 후처리

수집 자체는 `tools/` 가 한다. 여기서는 가져온 기사를 **쓸 수 있는지** 판단한다.

| 파일 | 판단 |
|---|---|
| `date_filter.py` | 이 기사가 대상 기간 안에 있는가 |
| `body_cleaner.py` | 본문에서 무엇을 버리고 무엇을 남길 것인가 |

## 날짜 필터가 보수적인 이유

발행일 파싱에 실패한 기사는 **버리지 않고 통과시킨다.** 매체마다 날짜 형식이
제각각이라 파서가 못 읽는 경우가 드물지 않은데, 실패를 배제로 처리하면 멀쩡한
기사가 조용히 사라진다. 중복 제거는 URL로 따로 하므로 통과시켜도 안전하다.

## 정제가 원본을 남기는 이유

`body` 는 그대로 두고 정제 결과를 `body_clean` 에 담는다. 후속 팩트체크 단계에서
"LLM이 쓴 내용이 원문에 있는가"를 대조하려면 원본이 필요하다. 정제본만 남기면
정제 과정에서 잘려나간 문장 때문에 오탐이 난다.

정제 후 본문이 `MIN_CLEAN_LEN` 미만이면 기사를 제외한다. 본문이 없으면 LLM이
제목만 보고 내용을 지어낸다.
