# illustration — 삽화

소제목별로 그림을 붙인다. 공급원은 `config/settings.py` 의 `IMAGE_SOURCE` 로 고른다.

| 값 | 동작 |
|---|---|
| `gemini` (기본) | AI 생성 (`generated_image_agent.py`) |
| `none` | 삽화 없이 진행 |

## 스톡 사진 경로를 제거한 이유

뉴스 원본 사진은 저작권과 초상권 때문에 쓸 수 없다. 언론사·통신사 사진은
재배포가 금지돼 있고, 태권도 기사 특성상 미성년 수련생이 찍힌 사진이 많다.
원본을 AI로 변형해도 2차적저작물이라 위험이 사라지지 않는다.

대안이던 스톡 사진(Pexels)은 저작권 문제는 없지만 기사 내용과 무관해,
'자료사진' 고지를 달아도 본문과 겉돌았다. 소제목에서 개념을 뽑아 생성하는
편이 글과 맞물린다.

## 무료 티어 주의

Gemini 이미지 모델은 무료 티어에 할당량이 배정되지 않아 **첫 요청부터 429** 가
날 수 있다. 그 경우 삽화 없이 글만 저장되고 발행은 계속된다
(`generate_for_sections()` 는 실패한 섹션을 조용히 건너뛴다).
삽화를 아예 끄려면 `IMAGE_SOURCE=none`.

## 임포트를 함수 안에서 하는 이유

`collect_images()` 는 `IMAGE_SOURCE=none` 일 때 이미지 모듈을 임포트하지 않는다.
최상단에서 가져오면 삽화를 끄고 쓸 때도 의존성이 설치돼 있어야 한다.

## 삽화 시점

품질 검사 **이후**, Notion 저장 **이전**이다. 검사를 먼저 하는 이유는 이미지
삽입 후에는 원고 구조가 바뀌어 문단·줄 통계가 LLM 출력 그대로가 아니게 되기
때문이다.
